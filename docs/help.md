# 篠笛チューナーの使い方

## 使い方

### チューナーを使う（計測モード）

1. アプリを起動し、マイクの使用を許可する
2. 初回起動時は、お使いの篠笛の調子を選んで「決定」をタップする。続けて、メーターの中央に「音階名」と「運指名」のどちらを表示するかを選んで「決定」をタップする（どちらもあとから設定で変更できる）
3. 画面下部の「計測」を選択する
4. 「計測開始」ボタンをタップする
5. 篠笛を吹くと、周波数とメーターがリアルタイムで表示される。メーターの中央には、設定に応じて音階名（階名と音名）または運指名が出る
6. メーターの針が真上（0セント）に近づき、中央の文字が緑（±10セント以内）になればチューニング完了
7. 「計測停止」ボタンをタップして終了する

### 演奏を録音する（録音モード）

1. 画面下部の「録音」を選択する
2. 「録音開始」ボタンをタップする
3. 演奏する
4. 「録音停止」ボタンをタップして保存する
5. 「プレイリスト」タブから録音ファイルを確認・再生できる

### 頭出しをする（先頭の無音を除去する）

1. 「プレイリスト」タブを開く
2. ファイルを左スワイプして「頭出し」ボタンをタップする
3. 先頭の無音区間を除去した新しいファイル（`[頭出し]元のファイル名.m4a`）が作成される
4. 元のファイルはそのまま残る（非破壊）

### 他アプリへ音声ファイルをエクスポートする

1. 「プレイリスト」タブを開く
2. エクスポートしたいファイルを左スワイプする
3. 「共有」ボタンをタップする
4. 共有シートから送り先のアプリを選択する

### 他アプリから音声ファイルをインポートする

1. ファイルアプリや他の音楽アプリで共有したいファイルを選ぶ
2. 共有シートを開き、共有先に「篠笛チューナー」を選択する
3. 「プレイリスト」タブに自動的に追加される
4. 対応フォーマット: m4a / mp3 / wav / aiff / caf / flac

### 周波数表を見る

1. 「周波数表」タブを開く
2. 選択中の調子の運指・階名・音名・周波数が、高い音から順に一覧表示される
3. 右上の歯車アイコンから、調子と階名（移動ド／固定ド）を変更できる（チューナーの設定と共通）

### 設定を変更する

#### チューナー設定

1. チューナー画面右上の歯車アイコン、または左上の調子表示（例「8本調子」）をタップする
2. 調子・階名（移動ド／固定ド）・メーターの表示（音階名／運指名）・グラフ表示・セント範囲・継続時間を変更できる
3. 計測中・録音中は設定を開けないため、停止してから変更する

#### プレイリスト設定

1. 「プレイリスト」タブ右上の歯車アイコンをタップする
2. 頭出しのしきい値（感度）を変更できる

## よくある質問

**Q. 音が検出されない**  
A. マイクへのアクセス許可が必要です。iOSの「設定」→「篠笛チューナー」→「マイク」をオンにしてください。

**Q. 30秒で自動的に停止する**  
A. 30秒間音が検出されなかった場合、自動停止します。仕様です。

**Q. チューニング成功のエフェクトが出ない**  
A. 設定で指定したセント範囲内に、指定した秒数以上ピッチが収まった場合に表示されます。設定画面でセント範囲や継続時間を緩めると表示されやすくなります。

**Q. 六本調子・八本調子以外の調子に対応していない**  
A. 現在は六本調子と八本調子に対応しています（基準ピッチ A4＝442Hz）。調子はチューナー画面左上の調子表示、または周波数表の設定ボタンから切り替えられます。他の調子は近日対応予定です。

**Q. 移動ドと固定ドの違いは？**  
A. 移動ドは、調子の主音（六本調子なら B♭、八本調子なら C）を「ド」と呼びます。同じ運指なら調子が違っても同じ階名になります。固定ドは、調子にかかわらず C を「ド」と呼びます（例: E♭ は「ミ♭」）。設定の「階名」で切り替えられます。

**Q. メーターに運指名を出したい／音階名に戻したい**  
A. チューナー設定の「メーターの表示」で「音階名」と「運指名」を切り替えられます。音階名では階名と音名（例「ド B♭5」）、運指名では篠笛の運指（例「一」「七の甲」）がメーターの中央に表示されます。初回起動時に選んだ設定がそのまま使われます。

**Q. 計測中に調子を変えられない**  
A. 計測中・録音中は、調子表示と歯車アイコンをタップできません。「計測停止」（録音中は「録音停止」）をタップしてから変更してください。周波数表タブの設定からは、計測中でも変更できます。

**Q. 録音ファイルを別のアプリに送りたい**  
A. プレイリスト画面でファイルを左スワイプすると共有ボタンが表示されます。

**Q. 録音ファイルを削除したい**  
A. プレイリスト画面でファイルを左スワイプすると削除ボタンが表示されます。

**Q. 録音ファイルの名前を変えたい**  
A. プレイリスト画面でファイルを左スワイプすると「名前を変更」が表示されます。

**Q. 頭出しをしても変化がない**  
A. しきい値が大きすぎると有音部分を無音と判定してしまいます。プレイリスト設定画面でしきい値を小さくしてください（デフォルト: 0.003）。

**Q. 他アプリの音声ファイルをインポートしたい**  
A. 対象ファイルの共有シートから「篠笛チューナー」を選択するとプレイリストに追加されます。ファイルアプリや Apple ミュージックなど、共有機能を持つアプリから送ることができます。
