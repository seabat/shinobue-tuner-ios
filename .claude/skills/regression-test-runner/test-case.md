# ぞめきチューナー リグレッションテストケース

このファイルは `regression-test-runner` スキル（`SKILL.md`）が実行のたびに自動で参照・更新する。
画面構成や機能が変わった場合、スキル実行時に現在のコードと照合してケースの追加・更新が行われる
（詳細は `SKILL.md` のステップ1を参照）。

- 「前提」列はケース実行前に用意する状態。リセット・テストデータの作り方は `../ios-ui-operator/recipe.md`
  「状態のリセット・テストデータの準備」を参照
- アンインストールを伴うケース（No.1〜2）は録音ファイル・設定を消すため、先頭にまとめて実行する
  （コピーしたテスト用音源も消えるので、No.22〜23 は No.1〜2 より後に実行し、直前に音源をコピーする）
- 文言はすべて日本語ロケール（`-AppleLanguages "(ja)"`）での表示
- 音程判定・セント値・祝福エフェクトの発火はシミュレータのマイク入力に依存するため対象外（ユニットテストの担当）。
  ただし、マイクの代わりに音声ファイルを入力にする No.22〜23（起動引数 `-UITestAudioFile`）は例外として対象にする
- 「結果」列は直近の実行結果のみを保持する（履歴は残さない）。書式は `SKILL.md` のステップ5参照
- FAIL の証跡スクリーンショットは同ディレクトリの `screenshots/` 配下に保存される
