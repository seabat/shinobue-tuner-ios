## 機能仕様

**モニタリング**（マイク入力〜ピッチ表示）→ **チューナー**（ソロ/アンサンブル判定とチューニング設定）→ **録音** → **プレイリスト** → **周波数表** の順とする。

| 順 | 見出し | 記載内容の要約 |
|----|--------|----------------|
| 1 | モニタリング機能 | 入力〜信号処理（**ピッチ検出のパラメータ**含む）、**チューナー画面の UI**、**セントメーター / 音階色**、**ピッチグラフ**（いずれも計測(単)・計測(複)・録音で共通） |
| 2 | チューナー機能 | **ソロ / アンサンブル**のチューニング成功判定、**チューニング設定** |
| 3 | 録音機能 | 録音、m4a 保存、プレイリスト更新トリガー |
| 4 | プレイリスト機能 | 保存ファイルの一覧・並び替え・再生・編集・共有・インポート |
| 5 | 周波数表 | 六本調子の参照用一覧（データはコード参照） |

### モニタリング機能

チューナータブにおいて、**計測(単)**・**計測(複)**・**録音**のいずれのモードでも同じマイク入力〜ピッチ算出〜画面表示のパイプラインを用いる（モード固有の判定や設定は **チューナー機能**で述べる）。

#### 入力・処理・出力

- **入力**: マイク（`AVAudioEngine` 経由）。マイク権限が未許可の場合は `PermissionRequestView` を表示し、許可後にチューナー画面へ遷移する。
- **処理**: FFT + HPS によるピッチ推定。有効音域 **100 Hz 〜 2600 Hz**。無音判定は **RMS < 0.003**（`AudioConstants.noiseThreshold` と一致）。
- **出力**:
  - 検出ピッチ **Hz**（無音時は 0）
  - 最近傍音の **NoteInfo** と **セント偏差**（無音時は非表示）
  - **セントメーター**（`-50` 〜 `+50` セント、無音時は非アクティブ表示）
  - 任意で **ピッチグラフ**（設定で On/Off）
- **セッション時間**: **計測（計測・単／計測・複）**または**録音**でセッション開始後、**0.05 秒ごと**に経過時間を更新し、無音タイムアウト判定に用いる。
- **無音タイムアウト**: 最後に **音を検出した時刻**から **30 秒**経過で自動停止。**計測（計測・単／計測・複）**では `stopMonitoring()`、**録音**では `stopRecording()`（ファイル保存まで実行）。アラート文言は録音か否かで切り替え。
- **バックグラウンド**: アプリがバックグラウンドへ遷移したとき、**録音中**（`isSavingRecording == true`）**でない**場合のみ `stopMonitoring()` し、計測を止める。**録音中**はマイク・ピッチ処理・ファイル書き込みを**継続**し、バックグラウンド遷移だけでは停止しない（`ContentView` の `scenePhase` ハンドラ）。

#### ピッチ検出アルゴリズムのパラメータ

挙動に影響する定数のみ記す（実装は Data 層のマイク／ピッチ処理）。

| 項目 | 内容 |
|------|------|
| **FFT** | Accelerate `vDSP_fft_zrip`、**ハン窓**、**FFT サイズ 4096** |
| **HPS**（倍音積スペクトル法） | **倍音数 3** で基音を推定 |
| **周波数の補間** | **放物線補間**でサブビン精度の Hz を算出 |
| **有効音域** | **100 Hz 〜 2600 Hz**（上記「処理」のピッチ推定対象と一致） |
| **無音判定** | **RMS < 0.003**（上記「処理」および `AudioConstants.noiseThreshold` と一致） |

#### チューナー画面の UI 構成

- 画面上部: **音階表示**（運指名・日本名・西洋名・Hz）
- 中央付近: **セントメーター**（バー上に `±0.1` 刻みのセント数値、有音時のみ）
- 下部: **コントロールバー**（開始/停止とモード切替）
- 右上: **設定**（歯車）。**計測（計測・単／計測・複）または録音**の動作中は無効
- チューニング成功時: **オーバーレイの祝福エフェクト**（`showTuningCelebration` が true の間）

**章の帰属（祝福エフェクト）**: **表示**（オーバーレイとして何が見えるか）は **モニタリング機能**の本節に記す。**発火条件**（いつ `showTuningCelebration` が true になるか）は **チューナー機能**の **チューニング成功判定**（ソロ／アンサンブル）および **チューニング設定**（セント範囲・継続時間など）で定義する。

#### セントメーター表示と音階名の色（視覚的閾値）

`NoteDisplayView`（音階名のアクセント色）および `CentsMeterView`（メーター帯のグラデーション）の実装と対応する。

| 条件 | メーター帯の意味合い（グラデーション） | 音階名のアクセント色 |
|------|----------------------------------------|----------------------|
| セント絶対値 ≤ **10** | 中央付近の緑寄り | 緑 |
| 10 < 絶対値 ≤ **25** | 黄寄り | 黄 |
| 絶対値 > **25** | 赤寄り | 赤 |

※ メーターは **±50 セント**でクリップ表示。チューニング「成功」判定の閾値は別途 **チューナー機能**の **チューニング設定**で決まる。

#### ピッチグラフ（表示設定が On のとき）

- **表示範囲**: 直近 **5 秒**のサンプル。`currentTime` に合わせてウィンドウが移動（無音時も時間軸は進む）。
- **縦軸**: **log2** スケール。**589.999 Hz 〜 2500.328 Hz**（三/D5 〜 4'/Eb7）にクリップ。範囲外のサンプルは折れ線を切る。
- **ガイドライン**: 六本調子の代表周波数に水平破線と Hz・音名ラベル。

### チューナー機能

祝福エフェクトの**見た目**は **モニタリング機能**の「チューナー画面の UI 構成」を参照。**成否の判定**は本章のソロ／アンサンブルおよび **チューニング設定**に従う。

#### ソロモニタリング機能

- **UI上のモード名**: 「計測(単)」。アクセント色 **シアン**。開始アイコン `mic.circle.fill`。
- **開始**: メインの開始ボタンで**計測をすぐ開始**する。アンサンブル用のスペクトル判定は使わない。
- **チューニング成功判定（ソロ）**:
  - **瞬時条件**: 入力を短い間隔ごとに判定する。次の **2 つすべて**を満たすとき、その時点で「チューニングが合っている」とみなす。
    1. **有音**であること（マイク入力から音が検出されている）。
    2. **音程**: 検出ピッチの基準音からのずれ（セント）が、**チューニング設定のセント範囲**以内である。
  - **状態遷移**: **同じ音階**が続く間だけ、「合っている」時間を積み上げる。**音階が変わると**積み上げは**ゼロに戻る**。「合っている」状態が **チューニング設定の継続時間**だけ続いたとき、**祝福エフェクト**を表示し、その後 **1 秒**は再発火を抑える（クールダウン）。
- **無音時**: 音符表示は `---` / 「音を鳴らしてください」。チューニング成功判定に使う積み上げはリセット。

#### アンサンブルモニタリング機能

- **運用前提**（判定が想定する利用状況）:
  - **1 台の端末・1 本のマイク**で、複数人の演奏を同時に拾う。
  - **演奏者は同じ音階（同じ音名）を吹く**こと。対象音階は**自動検出**し、事前に音階を選ぶ必要はない。
- **UI上のモード名**: 「計測(複)」。アクセント色 **緑**。開始アイコン `person.2.circle.fill`。
- **開始フロー**: 開始ボタンで **全画面カウントダウンモーダル**（**3 → 2 → 1 → はい！**）を表示。最終ステップで `startMonitoring()` を呼び、モーダルを閉じる。実行中は **モード切替を無効化**。
- **処理**: `EnsembleTuningDetector` がスペクトルとピッチを受け、フレームごとに `EnsembleTuningState` を出力。
  - **セント偏差**: 検出ピッチに対する最近傍音のセント（`NoteHelper`）。
  - **スペクトル幅**: ピークビン周辺で振幅がピークの **50%（-6 dB相当）** を超える連続ビン幅（ビン数）。
  - **安定性スコア**: 直近 **最大 30 フレーム**（`AudioConstants.ensembleBufferSize`）のセント列の **標準偏差**。1 フレームのみのときは 0。
  - **無音・不正値**: 周波数 0 等のときはセント・幅・安定性を 0、`isInTune = false`、バッファクリア。
- **チューニング成功判定（アンサンブル）**:
  - **瞬時条件**: 入力を短い間隔ごとに判定する。次の **3 つすべて**を満たすとき、その時点で「チューニングが合っている」とみなす。
    1. **音程**: 検出ピッチの基準音からのずれ（セント）が、**チューニング設定のセント範囲**以内である。
    2. **スペクトルのまとまり**: **スペクトル幅**（上記「処理」の定義）が、**チューニング設定のスペクトル幅閾値**以下である（デフォルト **5.0**）。
    3. **ピッチの安定**: **安定性スコア**（上記「処理」の定義）が、**チューニング設定の安定性スコア閾値**以下である（デフォルト **10.0**）。
  - **状態遷移**: **MIDI ノートは 0 固定**のため**音階変更によるリセットは行われない**。`isInTune` が **`durationSeconds` 秒**継続したとき `showTuningCelebration = true`、その後 **1.0 秒**のクールダウン。`TunerViewModel` の **チューニング成功判定用の状態遷移**（継続時間の積算・祝福表示・クールダウン）に従う（**ソロとの差**は MIDI ノートの扱いのみ）。

#### チューニング設定

- **画面**: チューナー画面の設定から **全画面モーダル**。閉じると `reloadSettings()` で ViewModel に反映。
- **永続化**: `TunerSettings` の変更は **変更のたびに UserDefaults へ保存**（`TunerSettingsViewModel`）。

| 項目 | 内容 |
|------|------|
| **調子** | ホイールで **1〜13 本調子**を表示。未対応を選ぶとアラートのうえ **六本調子に戻す**。実データ上の基準は **六本調子 = 筒音 442 Hz**（他調子も内部値は同じ）。 |
| **ピッチグラフ表示** | トグル（デフォルト On）。 |
| **セント範囲** | **±1〜±50** セント（1 セント刻み）。成功判定の瞬時許容幅。デフォルト **10**。 |
| **継続時間** | **0.5〜5.0 秒**（0.5 秒刻み）。デフォルト **1.0** 秒。 |
| **アンサンブル調整（非推奨）** | **スペクトル幅閾値** 1.0〜20.0（0.5 刻み、デフォルト 5.0）。**安定性スコア閾値** 1.0〜30.0（1 刻み、デフォルト 10.0）。 |
| **デフォルトに戻す** | 上表の各項目を**アプリ標準の初期値**にまとめて戻す。 |

**初回インストール後および「デフォルトに戻す」適用後**: 上表の各項目のデフォルト値に復る。具体的には、調子は**六本調子**、ピッチグラフは**表示**、セント範囲は **±10**、継続時間は **1.0 秒**、アンサンブル調整のスペクトル幅閾値は **5.0**、安定性スコア閾値は **10**。

**各 Section のフッター文言**（チューニング設定モーダル内の説明。現在の設定値が入る部分は、スライダー等の値に合わせて表示が変わる）:

| Section | 内容 |
|---------|------|
| **成功とみなすセント範囲** | ピッチが基準音から ±（現在のセント範囲設定）セント以内を「チューニング成功」とみなす、という説明に続けて **推奨: ソロ ±10 セント / アンサンブル ±15 セント** を表示。 |
| **成功とみなす継続時間** | セント範囲内のピッチが（現在の継続時間設定）秒間続いた場合に「チューニング成功」とみなす、という説明に続けて **推奨: ソロ 1.0 秒 / アンサンブル 0.5 秒** を表示。 |
| **アンサンブル 調整オプション（非推奨）** | 実機テスト中の値であること、変更で判定が不安定になる場合があること、最適値確定後に当設定を削除する予定であることを説明。 |

### 録音機能

- **UI上のモード名**: 「録音」。アクセント色 **オレンジ**。アイコン `record.circle`。
- **計測（計測・単／計測・複）との違い**: **録音**では `startRecording()` が `startMonitoring()` に加え **`AVAudioFile` へ AAC/m4a 書き込み**を開始する。
- **出力ファイル**: **Documents** に **`yyyy-MM-dd_HH-mm-ss.m4a`** 形式で保存。
- **停止**: `stopRecording()` で書き込み終了・監視停止。保存直後、**先頭の `fetchAll()` 結果を `lastSavedRecording` に設定**し、ルートでプレイリスト一覧の再読込をトリガー。
- **無音タイムアウト・バックグラウンド**: **モニタリング機能**の「**入力・処理・出力**」および同章の **無音タイムアウト**・**バックグラウンド**の説明に従う。30 秒無音でも録音は停止する。**録音**中はバックグラウンドでも監視・録音を継続し、バックグラウンド遷移では自動停止しない（上記と同じ `isSavingRecording` / `scenePhase` の条件）。

### プレイリスト機能

#### 一覧

- **データソース**: アプリ **Documents** 内の音声ファイル。**拡張子**: `m4a`, `mp3`, `wav`, `aiff`, `aif`, `caf`, `flac`。
- **並び順**: **プレイリスト設定**の `sortOrder`（デフォルトは **作成日時・新しい順**）。画面表示時および設定クローズ後に再適用。
- **空状態**: アイコンと案内文で「録音なし」を表示。

#### 行操作・再生

- **タップ**: 未再生時はそのファイルを選択して再生開始（再生位置 0 から）。**再生中は他行をタップできない**（ロック時、非選択行は半透明）。
- **スワイプ（再生中は非表示）**:
  - **削除**（確認アラート）
  - **名前変更**（拡張子は自動付与）
  - **共有**（Share Sheet）
  - **頭出し**: 先頭無音を除去した **`[頭出し]` 付き m4a** を生成（内部で無音検出に **設定のピーク閾値** を使用。デフォルト **0.003**）
- **下部コントロールバー**: ファイルが選択されているときのみ表示。
  - **シークバー**、**現在/総時間**、**再生/一時停止**、**停止（×）** — 停止で選択解除。
- **設定（プレイリスト画面右上）**: 並び替え・頭出ししきい値。変更は **UserDefaults** に保存。

#### その他

- **録音完了**: `ContentView` が `lastSavedRecording` 変化で `loadPlaybackFiles()` を実行。
- **インポート**: 共有などで渡された URL を `onOpenURL` から取り込み、重複時はファイル名に `_2`, `_3`… を付与。

### 周波数表

- **タブ**: 「周波数表」— ナビゲーションタイトル **「六本調子 周波数表」**。
- **内容**: 篠笛 **六本調子**の運指・日本名・西洋名・周波数（Hz）を **スクロール一覧**で表示。高い音から **4'（Eb7, 約 2500 Hz）** から **筒音（A4, 442 Hz）** まで。
- **強調表示**: **1'（Bb6）** と **筒音（A4）** の行をシアン系でハイライト。
- **全音程テーブル**: 運指・音名・Hz の一覧は本書では列挙しない。**実データの参照先**は `shinobuetuner/Presentation/View/FrequencyTable/FrequencyTableScreen.swift` 内の `rows` 配列（画面表示と同一ソース）。
