# 1.4.0 リリースノート

## App Store 掲載文（日本語）

・八本調子に対応
・初回起動時に調子を選べるように
・階名を移動ド／固定ドで切り替え可能に
・周波数表の画面から調子を変更可能に
・音程の判定精度を改善
・六本調子の音域表示を修正

## App Store Copy (English)

- Added support for the 8-hon tuning (hachihon-choshi)
- Choose your flute's tuning on first launch
- Switch solfège between movable-do and fixed-do
- Change the tuning from the frequency table screen
- Improved pitch detection accuracy
- Fixed the note range shown for the 6-hon tuning
